# Тестовое задание. SFTP Client
Задание 1. Консольное Java приложение для работы с SFTP сервером, на котором расположен файл доменных адресов.

## Сборка проекта
- Установить Java v8 и выше
- Установить Maven
- Клонировать репозиторий ```git clone <repository-url>``` 
- Перейти в корневую директорию проекта
- Очистить старые сборки ```mvn clean```
- Собрать проект ```mvn package```

Собранный проект будет находиться в папке ```target```

## Запуск проекта
Запустить приложение можно командой ```java -jar target\sftp-client-1.0-SNAPSHOT.jar```

После запуска приложения нужно поочередно ввести:
- host сервера
- port
- login
- password
- путь к существующему на сервере файлу (.json)

## Работа приложения
1. Получение списка доменов и ip-адресов
2. Получение ip по доменному имени
3. Получение доменного имени по ip
4. Добавление пары домен-ip
5. Удаление пары по домену
6. Удаление пары по ip
